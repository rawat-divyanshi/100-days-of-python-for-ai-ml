# 🧠 Key Concepts Learned

### List Creation

```python
fruits = ["Apple", "Banana", "Mango"]
```

### Accessing Elements

```python
print(fruits[0])
print(fruits[-1])
```

### Adding Elements

```python
fruits.append("Orange")
```

### Inserting Elements

```python
fruits.insert(1, "Grapes")
```

### Removing Elements

```python
fruits.remove("Banana")
```

### Sorting

```python
numbers.sort()
```

### Reversing

```python
numbers.reverse()
```

### List Comprehension

```python
squares = [x**2 for x in range(1, 6)]
```
