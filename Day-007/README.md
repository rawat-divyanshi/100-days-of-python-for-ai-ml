## 💡 Key Takeaways

- Nested Loops are used when one loop needs to run inside another.
- The `else` clause executes only if the loop finishes normally.
- Prime Numbers have exactly two factors.
- Factorial is repeated multiplication.
- Fibonacci Series is generated by adding the previous two numbers.
- Logic improves through consistent practice and problem-solving.
