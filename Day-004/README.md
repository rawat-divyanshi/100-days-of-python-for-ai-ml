## 🧠 Key Takeaways

* `input()` always returns a string.
* Type conversion allows changing one data type into another.
* Strings are sequences of characters enclosed in quotes.
* Python uses zero-based indexing.
* In slicing, the **start index is included** and the **stop index is excluded**.
* Strings are immutable, meaning individual characters cannot be modified.
* String methods simplify common text operations.
* f-Strings are the modern and recommended way to format strings.
