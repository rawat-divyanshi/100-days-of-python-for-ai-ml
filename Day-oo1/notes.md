# Introduction to Python

## What is Python?

Python is a high-level, interpreted programming language known for its simple and readable syntax. It is one of the most popular programming languages in the world.

## Why Learn Python?

- Easy to learn and use
- Large community support
- Huge collection of libraries
- Used in web development, automation, data science, and AI/ML

## Why Python for AI/ML?

Python has powerful libraries that make AI and Machine Learning development easier, such as:
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow
- PyTorch

## Summary

Python is beginner-friendly, versatile, and the most widely used language in AI and Machine Learning.
