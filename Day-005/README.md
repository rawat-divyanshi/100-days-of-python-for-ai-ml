# 💡 Key Takeaways

- Every condition evaluates to either **True** or **False**.
- Python uses **indentation** to define blocks of code.
- `if` executes code only when a condition is true.
- `else` executes when all previous conditions are false.
- `elif` allows checking multiple conditions.
- Nested `if` helps solve complex decision-making problems.
- The ternary operator provides a short and clean way to write simple conditions.
