# Day 008 – Functions (Part 1)

> *"Functions help us write code once and use it many times."*

Welcome to **Day 008** of my **100 Days of Python for AI/ML** journey.

Today, I learned one of the most important concepts in programming—**Functions**. Instead of writing the same code repeatedly, functions allow us to organize code into reusable blocks, making programs cleaner, easier to understand, and easier to maintain.
