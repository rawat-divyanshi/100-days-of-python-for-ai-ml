# Quick Revision

### Loop Types

- `for` Loop
- `while` Loop

### Loop Control Statements

- `break`
- `continue`
- `pass`

### range() Forms

```python
range(stop)
range(start, stop)
range(start, stop, step)
```

### Remember

- `break` → Exit the loop
- `continue` → Skip current iteration
- `pass` → Do nothing (placeholder)
