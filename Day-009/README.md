# 💡 Key Takeaways

- Local variables exist only inside functions.
- Global variables can be accessed throughout the program.
- Use the `global` keyword to modify global variables.
- `*args` accepts unlimited positional arguments.
- `**kwargs` accepts unlimited keyword arguments.
- Lambda functions provide a concise way to write simple functions.
- Recursion allows a function to solve a problem by calling itself.
- Every recursive function must have a base case to prevent infinite recursion.
